## Hinweis zur Datenerhebung

Falls TikTok für Business-/Creator-Konten eine offizielle API mit
Zustimmung anbietet, ist diese einer Browser-Scraping-Lösung vorzuziehen.
Web-Scraping des eigenen Kanals über den persistenten Browser
(`docs/BROWSER.md`) ist als Fallback zulässig, solange es sich um deinen
eigenen, eingeloggten Account handelt und keine Nutzungsbedingungen
umgangen werden (keine automatisierten Massenabfragen, keine
Ratenlimit-Umgehung).
